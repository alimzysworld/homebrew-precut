# Homebrew tap for precut

```
brew install --cask alimzysworld/precut/precut
```

[precut](https://sidething.com/precut) is a video pre-editor for short-form creators that runs on your Mac and works with your own Claude Code or Codex. Apple silicon, macOS 14 or later. Source: [alimzysworld/precut](https://github.com/alimzysworld/precut).

precut updates itself after install. `brew uninstall --cask precut` removes the app; add `--zap` to remove its settings and caches too.
